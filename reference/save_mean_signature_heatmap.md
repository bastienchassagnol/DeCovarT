# Tile heatmap of the unscaled mean signature \\\mu\\

Tile heatmap of the unscaled mean signature \\\mu\\

## Usage

``` r
save_mean_signature_heatmap(true_theta, file, data_rds = NULL)
```

## Arguments

- true_theta:

  A `true_theta` list (`mu` is \\G\times J\\).

- file:

  Output PDF path.

- data_rds:

  Optional directory for the ggplot `data` RDS.

## Value

`file`, invisibly.

# Q-Q plot of joint Mahalanobis D^2 versus chi-square_J-1

Q-Q plot of joint Mahalanobis D^2 versus chi-square_J-1

## Usage

``` r
plot_mc_chi2_qq(df, title = NULL)
```

## Arguments

- df:

  Table with `mahalanobis`, `algorithm`, `chi_df`, and `panel`.

- title:

  Page title.

## Value

A `ggplot`.
